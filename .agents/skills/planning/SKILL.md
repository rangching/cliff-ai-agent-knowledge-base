# 需求規劃

先遵守根目錄 AGENTS.md。

1. 讀 Issue、AGENTS.md、現有程式與 CI，先確認 task scope。
2. 列出已知事實、assumptions、待查證事項、non-goals 與依賴。
3. 提出按順序的 implementation plan、預計檔案、風險與回復方式。
4. 將每個驗收條件對應具體測試或人工查驗；不可杜撰測試工具。
5. 將計畫寫入 Issue，指定角色與 Writer Lock；缺少必要權限時先完成不受影響的讀取工作。
